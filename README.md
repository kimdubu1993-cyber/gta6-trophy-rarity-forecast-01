Forecast each GTA VI trophy's Exophase earn rate at 2026-11-26 00:00 UTC as five quantiles, from the house-recorded reads up to the deadline. Python 3.13, standard library only. A saturating log-time growth curve per trophy, with an honest spread that combines a random-walk term, the fit residual, and a refresh-uncertainty floor.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
